
Loops-with-branching
Учебный проект на C++ по теме «Циклы с ветвлением»: программы, в которых внутри цикла (for, while, do-while) выполняются условные операторы (if/else, switch).

Состав репозитория
Файл	Назначение
Loops-with-branching.cpp	Исходный код программы (функция main)
Loops-with-branching.vcxproj	Файл проекта Visual Studio
Loops-with-branching.vcxproj.filters	Группировка файлов в обозревателе решений
.gitignore	Исключения для Git (артефакты сборки Visual Studio)
LICENSE	Лицензия MIT
Текущее состояние
Сейчас в Loops-with-branching.cpp находится стартовый шаблон Visual Studio, который выводит Hello World!. Решение задания ещё не добавлено.

Требования
Windows
Visual Studio 2019/2022 с рабочей нагрузкой «Разработка классических приложений на C++»
Сборка и запуск
Visual Studio
Клонируйте репозиторий:
git clone https://github.com/marginal23/Loops-with-branching.git
Откройте Loops-with-branching.vcxproj в Visual Studio.
Запуск без отладки — Ctrl+F5, с отладкой — F5.
Из командной строки
Файл можно собрать и без Visual Studio, любым компилятором C++:

g++ -std=c++17 -o loops Loops-with-branching.cpp
./loops
Пример вывода
Hello World!
